提案者：hypothesis generator agent
日期：2026-09-18
資料版本：93 集（2026-05-07 ~ 2026-09-16）、2259 筆推薦、1632 個有 d3 超額的去重部位

## 0. 先講三件事（否則下面每個假說都會被誤讀）

**(a) 我刻意沒有偷看報酬。**
本文所有數字都是「筆數、欄位覆蓋率、文字關鍵詞頻率、樣本量」，我沒有對任何候選篩選條件計算過超額報酬。理由：如果我先跑一輪、挑出數字最好看的角度再寫成「假說」，那第三個 agent 的「獨立驗證」就是驗證我的 data dredging，整條防線就廢了。以下每個假說的方向（正/負號）都是**事前**從機制推出來的，而且寫死在文件裡，驗證時只能照著測。

**(b) 我在核對資料時發現前一輪有一個確定的 bug。**
`scripts/strategy_search.py` 的 `bull_regime_only_m1`：

```python
def bull_regime_pred(p):
    r, ex = p["ret"].get("m1"), p["excess"].get("m1")
    return (r - ex) > 0   # 大盤原始報酬 > 0
```

`r - ex` 是「這個部位**持有期間**的大盤報酬」——那是未來資訊。這個策略等於「只買那些事後證明大盤會漲的日子」，不管結果是什麼都不可執行。前一輪「大盤多頭月份濾網失敗」這條結論，其實根本沒被有效測過（假說 H12 是它的無未來資訊版本）。

**(c) 我認為前 18 個策略全滅有一個結構性原因，不是運氣問題。**
每集平均 20.7 筆有方向的推薦、去重後仍有 ~18 個部位；一天一集、持有 3 天 ⇒ 帳上同時約 **54 個部位**，母體 362 檔股票。這個投資組合在數學上就是「一籃子台股中小型股 + beta ≈ 1.2」，追蹤誤差本來就接近零。**一個複製大盤的組合不可能有 alpha，跟選股能力好不好無關。**
而前 18 個策略裡，有 14 個做的事情是「在 1857 個部位裡砍掉一部分」，砍完還剩 300~1600 個部位——依然是closet indexing。真正沒被動過的三個維度是：

1. **進場條件**（不是「買哪些」，而是「什麼價位才買、買不到就不買」）
2. **報酬定義**（把 beta 剝掉之後還剩什麼）
3. **組合建構**（集中度、部位大小、出場規則）

下面 12 個假說有 9 個集中在這三個維度。

## 1. 驗證規格（所有假說共用，請驗證 agent 嚴格遵守）

| 項目 | 規定 |
|---|---|
| 部位去重 | 沿用 `build_dashboard._episode_positions` / `strategy_search.build_positions`（同集＋同標的＋同方向併成 1 筆） |
| 成本 | `ROUNDTRIP_COST = 0.0057`，所有可執行策略都要出淨值。限價單策略要額外扣 0.1% 滑價假設 |
| 多空符號 | `sign = -1 if 看空 else 1`，`excess` 是未調整的原始值 |
| **推論單位** | **不可以再把 n=1632 當獨立樣本。** 同一集的 18 個部位共享同一個大盤衝擊，橫斷面相關性極高。有效樣本接近 **93 個集數日**。統計檢定一律用「以集數日為單位的組合日報酬」或 **block bootstrap（以日期為 block，1000 次）**，t 值用 Newey-West（lag = 持有天數）。前一輪報的 p=0.028 幾乎確定是被高估的（低估了 p），這條要先修 |
| 多重比較 | 本文共 12 個假說。**事前宣告**檢定家族大小 = 12，用 Benjamini–Hochberg FDR 控制在 0.10，或 Bonferroni α = 0.05/12 = 0.0042。任何假說內部若再細分成 5 個桶，桶內單獨顯著不算數，**只有「單調性」算數**（見下） |
| 單調性優先 | 凡是連續變數的假說，一律切 5 分位測「Q1→Q5 是否單調」，並用 Spearman rank correlation + 整體斜率檢定，而不是「找出最好的那個桶」。單一好桶 = 雜訊；5 桶單調 = 訊號 |
| 離群值 | 沿用 `top2_share_of_gain`，>0.5 一律標記。另外加一條：**去掉最好的 5% 部位後，結論必須不變號** |
| 時間穩定性 | 沿用全域中位切點的前/後半段，外加 `walk_forward.py` 的滾動出樣本 |
| 樣本門檻 | n < 30 的假說直接標記為「不可結論，只能存查」 |

### 成本這關有多硬（請先算清楚再決定要不要做）
持有 3 天 ≈ 一年 83 個來回 ⇒ 年化成本拖累 **0.57% × 83 ≈ 47%**。
換句話說 **d3 策略的毛超額必須穩定 > 1.0%/筆才有意義**，這是一道非常高的牆。這也是為什麼 H10（出場規則）和 H9（集中到每集 2 檔）在我心中權重很高：它們是唯二能「提高每筆毛邊際」而不是「再加一個濾網」的方向。

### ⚠ 逐字稿的硬限制（會殺掉一整類提案，先說清楚）
我實測了 93 份逐字稿對 2259 筆推薦的可定位性：

- **股票名稱能在逐字稿中原字串找到的只有 1225/2259（54%）**。ASR 同音錯字極嚴重：奇鋐→「齊鴻/騎鴻/起哄」、國巨→「國具/國劇」、鴻海→「洪海」、輝達→「灰達/蕙達」。
- **老師姓名只有 58/277 次能在逐字稿裡找到**（人名幾乎全被 ASR 打壞）。
- quote 欄位前 12 字能原字串命中的只有 874/2259。

⇒ **任何「用正則表達式在逐字稿裡數關鍵詞、再歸屬到某檔股票」的提案都不可靠**，會有 46% 的系統性遺漏，而且遺漏跟股票知名度相關（冷門股更容易被 ASR 打錯 ⇒ 偏誤不是隨機的）。
⇒ 文本特徵請一律走 **LLM 重抽取**（`analyze_free.py` 加欄位），不要走字串比對。
✅ 一個好消息：我驗證了 **JSON 裡 picks 的排列順序 = 老師在節目上討論的順序**（用 quote 在逐字稿中的位置做 concordance test：1366 concordant vs 300 discordant，一致度 0.82）。所以「這是他這段的第幾檔」是免費、可靠、且完全沒被用過的特徵（H4 用它）。

### H1｜老師自己說「別現在買」的那 41%，我們卻全部在隔天收盤買了

**1. 假說陳述**
把 `action` 欄位明確寫著「拉回／回檔／逢低／不要追／等回測」的推薦排除掉，只買「老師當下就叫你進場」的推薦，d3 超額會顯著高於現行 baseline；而被排除的那組會顯著較差。

**2. 為什麼可能成立**
現行回測把所有推薦一律在隔天收盤買進，但實測 **1928 筆有方向的推薦裡有 792 筆（41%）的 action 明講要等拉回**（去重後 695 個部位）。老師說「等拉回」的時候，他傳達的是「這檔現在的位階我不喜歡，風報比不好」。無條件在隔天收盤買進，等於**系統性地專挑分析師本人認為最不該追的那一半**進場——這是一個負向選擇偏誤，不是中性的。這也剛好解釋了為什麼 baseline 幾乎沒有訊號：好訊號（立即可買）和反訊號（別追）被混在同一個平均數裡互相抵銷。

**3. 精確操作化定義**
- WAIT 詞表（只掃 `action` 欄位，不掃 quote）：`拉回 / 回檔 / 逢低 / 回測 / 壓回 / 若回 / 等回 / 等待 / 不要追 / 不宜追 / 回補`
- 部位層級：只要有任一位貢獻老師的 action 命中 WAIT ⇒ 該部位標 `WAIT`，否則標 `IMMEDIATE`。
- 三組對照：`IMMEDIATE`(965 部位) / `WAIT`(695) / baseline(1632)，horizon = d3、w1，出毛/淨超額 + 日期 block bootstrap。
- **事前預測方向：IMMEDIATE − WAIT > 0。** 若符號相反（WAIT 更好），視為假說被否定，不得改口解釋。
- 穩健版：用 `analyze_free.py` 加一個 `entry_timing: "immediate" | "on_pullback" | "on_breakout" | "watch_only"` 的 enum 欄位重抽 93 集，用 LLM 判斷取代詞表，兩種標記法結論須一致。

**4. 為什麼這次不一樣**
前 18 個策略篩的全是「**誰**說的（core5、排除輸家）」和「**多有信心**（confidence、共識人數）」——都是講者屬性。從來沒有人篩過「**他到底叫你做什麼**」。而且這不是再加一個濾網去切小樣本，它是在修正一個**執行面的錯配**：回測的進場方式跟推薦內容根本不匹配。

**5. 可執行性檢查**
✅ 完全乾淨。`action` 是節目播完當晚就有的文字，不含任何價格或未來資訊。判斷邏輯純文字，隔天開盤前就能決定名單。

**6. 預估樣本量**
IMMEDIATE 965 部位、WAIT 695 部位（皆為有 d3 超額的去重部位），兩組都遠超門檻。跨 93 個集數日，前後半段各約 480 筆。**這是本文樣本最充足的假說。**

### H2｜真的照老師的話下限價單（而不是無視他）

**1. 假說陳述**
對 H1 中的 WAIT 組，不在隔天收盤市價買進，改成掛一張限價單等拉回；有成交才算部位，5 個交易日沒成交就作廢。成交的那批部位，d3/w1 淨超額顯著為正。

**2. 為什麼可能成立**
兩個獨立的機制疊加：
(i) **避開注意力價格衝擊**——電視點名隔天的買盤是散戶注意力驅動的（Barber & Odean 2008 的 attention-buying；美國 Mad Money 的 Cramer effect 也是隔日開盤衝高、數日內回吐）。用限價單等回檔，等於讓別人去付那個溢價。
(ii) **老師的預期本身有資訊**——他說會拉回到月線，若真的拉回到月線，代表他對這檔的短期結構判斷是對的，成交的那批是「預測被驗證」的子集合。

**3. 精確操作化定義**
- 對每個 WAIT 部位，播出日 D：限價 `L = min(Close_D × 0.98, MA20_D)`（MA20 用 D 日含當日往前 20 個交易日收盤均價）。
- 有效期 D+1 ~ D+5（5 個交易日）。
- 成交判定：某日 `Low_t ≤ L` ⇒ 成交，成交價 `min(L, Open_t)`（跳空低開就用開盤價，保守）。
- 持有：自成交日起 3 / 5 個交易日，收盤出場。超額對齊大盤同區間（沿用 `bench_windows_aligned` 的做法，不可用不同區間比）。
- 成本：`0.0057 + 0.001`（限價單滑價/未成交機會成本緩衝）。
- **必要的兩個對照組**（缺一不可，否則結論無效）：
  - **對照 A（未成交組）**：沒被填到的那批，若照 baseline 在 D+1 收盤買會如何 ⇒ 檢查限價單是不是只是在「避開會漲的股票」。
  - **對照 B（安慰劑）**：把完全相同的限價規則套到 **IMMEDIATE 組**。如果 IMMEDIATE 組套限價也一樣好，那賺的是通用的短線均值回歸，**跟老師的指示無關**，H2 就被否定（但那本身也是一個發現）。
- **事前預測方向：WAIT 組限價進場 > WAIT 組市價進場，且 > IMMEDIATE 組套同一限價規則。**

**4. 為什麼這次不一樣**
前一輪唯一動過進場的是 `entry_delay.py`，測的是「晚 0/1/2/3 天用市價買」——那是**時間**維度。這裡動的是**價格**維度（訂單類型），是完全沒被碰過的自由度。而且它直接攻擊已知事實 #1（「晚 2 天進場邊際就衰減到 0」）：晚 2 天市價買是無條件追價，跟「等到跌下來才買」在經濟意義上是相反的操作。

**5. 可執行性檢查**
✅ 限價單在播出當晚就能掛好，成交與否由隔天之後的 Low 決定，沒有未來資訊。
⚠ 三個要小心的地方：(a) 必須用 Low 判成交、用 `min(L, Open)` 定價，不能用 Close 近似；(b) 台股漲跌停 10%，跳空跌停時掛在中間的單其實不一定成交得到，建議做一個「跌停日不成交」的保守版本做敏感度分析；(c) 成交的樣本天生是「有下跌」的子集合 ⇒ **對照 A 是必須的，不是選配**。

**6. 預估樣本量**
WAIT 部位 695 筆，5 日內觸及 −2% 的機率以台股個股波動推估約 45~60% ⇒ **預估 310~420 個成交部位**。夠。但跨前後半段各只剩 ~180，時間穩定性檢定會稍微吃緊。

### H3｜位階（股價的伸展程度）——老師自己天天在講，我們卻一次都沒量化

**1. 假說陳述**
在推薦當下，股價相對 20 日均線／60 日高點越「伸展」（漲太多），d3 超額越差；這個關係在 5 分位上是單調的。

**2. 為什麼可能成立**
逐字稿裡「位階」「漲多了不要追」「相對低位階」「補漲」是老師每一集都在用的核心語彙，但這個變數從來沒被量化過。機制上有兩股力量互相打架，正好可以分出勝負：
- **注意力耗盡／價格壓力反轉**：一檔已經連拉三根、爆量創高的股票，被電視點名時，邊際買盤早就進場了，隔天的散戶是最後一棒 ⇒ 伸展越大、反轉越大（預測負相關）。
- **52 週新高效應／動能延續**（George & Hwang 2004）：接近新高的股票因為錨定而反應不足，後續續漲。
兩者相反，這個檢定有實質的可否證性——不是「試試看」。

**3. 精確操作化定義**
播出日 D（用 D 日收盤前的資料，全部可得）：
- `ext20 = Close_D / MA20_D − 1`
- `near_high60 = Close_D / max(High_{D-59..D}) − 1`（≤0，越接近 0 越貼近高點）
- `ext_z = ext20 / (ATR20_D / Close_D)`（波動標準化版，避免高波動股天生 ext 大）
- 三個變數**分別**做兩種排序：(a) 全樣本 5 分位；(b) **同一集內** 5 分位（更好，因為同集共享大盤衝擊，beta 自動抵銷）。
- 檢定：Spearman rank corr(特徵, sign×excess_d3) + 5 桶單調性 + Q1 vs Q5 的 block bootstrap 差異。
- **事前預測方向：負相關（越伸展越差）。** 理由：已知事實 #1（只有 d3 有微弱訊號、m1 轉負）本身就是「先衝後回吐」的形狀，這跟價格壓力反轉一致，跟動能延續不一致。

**4. 為什麼這次不一樣**
這是第一次把**價格的脈絡**帶進來。前 18 個策略只用推薦的中繼資料（誰、多有信心、幾檔、第幾次），從來沒問過「這檔股票當時長什麼樣子」。而且這是**連續變數的單調性檢定**，不是找一個門檻——單調性遠比單一好桶難用運氣做出來，對 data dredging 的抵抗力高得多。

**5. 可執行性檢查**
✅ 全部用 D 日（含）以前的價格，播出當晚就算得出來。
⚠ 不可用 `auto_adjust` 之後的價格去回推歷史 MA 與當時實際掛牌價的關係（除權息會扭曲「前高」的心理意義）；建議 MA/ATR 用還原價（一致性），但「距離前高」另外用未還原價算一版做敏感度。

**6. 預估樣本量**
全部 1632 個部位，每個 5 分位 ~326 筆；同集內分位則是 93 集 × 每集約 3~4 筆/桶。充足。

### H4｜只買老師那一段的「頭號牌」（開場第一檔）

**1. 假說陳述**
只取每位老師在他那段節目裡**第一檔**討論的股票，d3 超額顯著優於他後面講的其他檔。

**2. 為什麼可能成立**
一位老師一集平均講 7 檔（實測 2~16 檔）。在一個 50 分鐘、三人平分的節目裡，**排序即優先序**：講者會把準備最充分、最想讓觀眾記住的想法放在最前面，後面幾檔常常是為了填滿時間、回應主持人追問、或順帶補充族群成員。後段的推薦資訊密度較低，是雜訊。
這同時解決結構問題 (c)：把每集 18 個部位砍到 3 個 ⇒ 組合終於有追蹤誤差，不再是closet index。

**3. 精確操作化定義**
- 特徵 `pick_rank` = 該筆在該老師 picks 陣列中的索引（只計入有方向的推薦，0-based）。**這個順序我已驗證與逐字稿順序一致度 0.82**（1366 vs 300 concordant pairs）。
- 三個 cohort：`rank==0`（256 部位）、`rank<=1`（515）、`rank>=3`（其餘）。
- 主檢定：`rank` 與 sign×excess_d3 的 Spearman 相關（**預測為負：排越後面越差**），加上 rank 0/1/2/3/4+ 五桶單調性。
- 組合版：每集取「三位老師各自的第一檔」= 每日 3 個部位，做成日頻組合曲線，出 Sharpe / IR，扣成本後與買進持有加權指數對比。

**4. 為什麼這次不一樣**
前一輪測過「精選日」（老師當集點名 ≤5 檔）——那是**老師層級**的話多話少。這裡是**同一位老師、同一集內部**的排序，把老師個人效果、當日大盤效果全部控制掉，是真正的橫斷面比較。而且這是唯一一個把部位數降到每日 3 檔（甚至 1 檔）的提案之一，才有可能產生真的 alpha 而不是抄大盤。

**5. 可執行性檢查**
✅ 順序資訊在節目播出當下就存在。

### H5｜論證深度＝準備程度（costly signaling）

**1. 假說陳述**
一筆推薦附帶的理由條數越多、且有明確數字目標價者，d3 超額越高；單句帶過的「填充式」推薦顯著較差。

**2. 為什麼可能成立**
講一個自己真的研究過的想法是有準備成本的：你會講得出三條理由、講得出估值、講得出目標價。隨口帶一句「XX 也可以注意一下」不需要任何成本。這是標準的 costly signaling——**成本高的訊號比較可信**。關鍵是：這個特徵是**機械性的文本屬性**，不是 LLM 的主觀評分。
現況分布：reasons 條數 1 條 205 筆 / 2 條 550 / 3 條 679 / 4 條 220 / 5+ 47；`target_price` 非空 471 筆，其中**去掉純支撐位描述、含明確上檔數字的有 262 個部位**。

**3. 精確操作化定義**
- `elab = n_reasons + 1·[有數字上檔目標價] + 1·[len(quote) ≥ 40 字]`（等權，不得調參）
- 目標價解析：`target_price` 含 `\d{2,6}` 且**不含** `支撐|不破|跌破|守` ⇒ 視為上檔目標。
- 分桶：`elab` 的 5 分位（或直接用 n_reasons 1/2/3/4/5+ 五桶），做單調性檢定。
- 附帶測「距離目標價幅度」：`upside = target_price / Close_D − 1`，只在 262 個部位上做 5 分位。**預測：upside 過大（>40%）反而較差**（畫大餅），呈駝峰而非單調 ⇒ 這是一個非單調的事前預測，若真的出現駝峰，反而是比較難用運氣做出來的證據。
- **事前預測方向：elab 與 excess_d3 正相關且單調。**

**4. 為什麼這次不一樣**

**5. 可執行性檢查**
✅ 純文字，播出當晚可得。
⚠ 最大弱點：reasons 條數由 LLM 抽取決定，可能反映的是**逐字稿長度**而不是老師的準備程度。必須做一個檢查：`n_reasons` 與「該老師當集總推薦數」的相關性——如果老師講 12 檔時每檔理由都少、講 4 檔時每檔理由都多，那 `elab` 只是「精選日」的替身（而精選日已被證偽）。**做法：在同一個老師×同一集內部做 z-score 標準化後再分桶。**

全 1632 部位、每桶 ~326。目標價子樣本 262 筆（每桶 ~52，偏薄但可用）。

### H9｜每集只買 2 檔：同集內綜合排序（beta 在這裡自動抵銷）

**1. 假說陳述**
在**同一集內部**用一個事前寫死的等權綜合分數排序 18 個部位，只買分數最高的 2 檔，扣成本後 d3 淨超額顯著為正。

**2. 為什麼可能成立**
兩個理由：
(i) **beta 自動抵銷**：同一集的所有推薦共享完全相同的進出場日與大盤環境。在集內做橫斷面排序，等於做了一個完美的日期固定效果控制——大盤怎麼走、β 有多高，對「集內排名」幾乎沒有影響。這是不用估 β 就達到近似 beta 中性的窮人作法。
(ii) **集中度**：每日 2 檔 vs 18 檔。如果訊號是真的但很弱（每筆 +1%），分散到 18 檔會被稀釋到看不見；集中到 2 檔才有機會讓 0.57% 的成本相對變小。這是唯一能同時對抗「closet index」和「成本牆」的結構。

**3. 精確操作化定義**
綜合分數（**等權相加，禁止調權重，禁止事後換組件**）：對每集內部的每個部位，計算四個變數的**集內 z-score** 後相加：
```
score = z(immediate)      # H1: IMMEDIATE=1, WAIT=0
      + z(elab)           # H5: n_reasons + 有數字目標價 + quote長度>=40
      + z(-crowd_10)      # H8: 前10集被推次數，取負
      + z(-ext20)         # H3: 相對MA20伸展度，取負
```
每集取 score 最高的 2 筆（平手時取 ticker 較小者，保持決定性）。持有 3 日與 5 日兩版。
- 對照：同一集分數**最低**的 2 筆（如果 score 有用，這組應該顯著較差；若兩頭都沒差，代表 score 沒有鑑別力）。
- **事前預測方向：Top2 > Bottom2，且 Top2 淨超額 > 0。**

**4. 為什麼這次不一樣**
前一輪的 `weighted_score_top20pct` 有三個致命差異：(a) 它是**每週**取前 20%（樣本仍有數百筆，還是分散）；(b) 它的四個組件（confidence、共識人數、core5、精選日）**全部是已經被個別證偽的東西**——四個壞訊號加起來不會變成好訊號；(c) 它用的是絕對分數而非集內相對排序，所以沒有抵銷掉日期效果。本提案的四個組件全部來自本文尚未被測試的新特徵，而且是集內排序 + 極度集中。

**5. 可執行性檢查**
✅ 四個組件全部在播出當晚可得（ext20 用當日收盤價）。
⚠ 這是一個**組合式假說**：它同時依賴 H1、H3、H5、H8 四個成分。**必須先跑完那四個、確認各自的符號方向，再跑 H9**；如果四個裡有三個是反的，H9 就不該用這個公式跑（否則就是在事後湊配方）。這一條請驗證 agent 嚴格遵守順序。

**6. 預估樣本量**
93 集 × 2 = **最多 186 個部位**（扣掉資料缺漏約 180）。過門檻但偏薄，前後半段各 ~90。**必須配合日期 block bootstrap，而且對離群值特別敏感——請務必做「去掉最好的 5 筆」測試。**

### H10｜出場規則：把固定 3 天改成波動標準化的停利停損括弧

**1. 假說陳述**
把「固定持有 3 個交易日收盤出場」改成「+2×ATR 停利 / −1×ATR 停損 / 10 日時間停損，先到先算」，每筆的**毛**期望值會顯著高於固定 d3，足以跨過 0.57% 的成本門檻。

**2. 為什麼可能成立**
已知事實 #1 的形狀（d3 微正、m1 轉負）代表：如果有效果，它是一個**在前幾天發生、之後被吐回去的脈衝**。固定 3 天的窗口會做兩件壞事：把還在噴的部位提前砍掉、把已經開始回吐的部位繼續抱著。用波動標準化的括弧單可以：
- **截斷左尾**——這正是已知事實 #5（跌時虧損是漲時獲利 6 倍）的直接對策。那個 6:1 的不對稱有一部分是 β，但另一部分是「沒有停損」。
- **讓贏家跑久一點**——這是唯一能提高每筆毛邊際的機制。在 0.57%/筆的成本結構下，**再多的濾網都不如讓每筆賺更多**。

**3. 精確操作化定義**
- `ATR20_D` = D 日為止 20 日 ATR，`atr_pct = ATR20_D / Close_D`
- 進場：D+1 收盤（與 baseline 一致，才能單獨隔離「出場規則」的效果）
- 括弧：停利 `entry × (1 + 2·atr_pct)`、停損 `entry × (1 − 1·atr_pct)`、時間停損 10 個交易日
- 路徑判定用日 OHLC：**同一天同時觸及停利與停損時，一律算停損**（最保守）
- 出場價：觸價出場用觸發價；時間停損用第 10 日收盤
- 對照：完全相同的部位母體，分別跑 d3 / w1 / w2 / m1 / 括弧單，**同一張表並列**
- 參數敏感度：(2,1) / (3,1.5) / (1.5,1) 三組都要跑，**如果只有其中一組好看，就是過擬合，直接判定失敗**
- **事前預測方向：括弧單的毛期望值 > d3，且左尾（5% 分位）明顯收斂。**

**4. 為什麼這次不一樣**
前 18 個策略、`entry_delay.py`、`walk_forward.py` 全部只動「買哪些、什麼時候買」，**出場規則從頭到尾是固定的常數**。這是一個完全沒被探索過的自由度，而且是唯一直接針對成本牆和左尾不對稱的方向。

**5. 可執行性檢查**
✅ 括弧單（OCO）在台股券商 API 可實現；ATR 用歷史資料算。
⚠ 日 OHLC 無法分辨當日誰先觸發，所以**必須**用「都算停損」的保守假設，否則會系統性高估。若結果只在樂觀假設下成立，視為失敗。
⚠ 停損被觸發的部位成本仍是 0.57%，高週轉不會變便宜——要如實扣。

**6. 預估樣本量**
全 1632 部位。無篩選，**這是最不會有樣本問題的假說。**

### H11｜部位大小：反波動率加權 ＋ 用組合層級（而非每筆平均）來評估

**1. 假說陳述**
把「每筆等權」改成「權重 ∝ 1/ATR%」，組合層級的資訊比率（IR）會顯著改善，即使每筆平均超額完全沒變。

**2. 為什麼可能成立**
現行所有評估都是「平均每筆超額」。這個指標有一個隱藏假設：每筆押一樣多錢。但一個 ATR 8% 的上櫃小型股和 ATR 2% 的台積電押一樣多錢，等於**在最波動的名字上押了 4 倍的風險**。如果 alpha 大致與風險成正比（常見情形），那等權 = 把賭注押在雜訊最大的地方，IR 必然受損。
更重要的是：這也解釋了前一輪反覆出現的 `top2_share_of_gain > 0.5`（結論被最好的 2 筆撐起來）——**那本來就是等權 + 高波動標的的必然數學後果**，不一定代表策略是假的，也可能代表評估方式是錯的。反波動加權會直接讓那個病徵消失或不消失，兩種結果都有資訊。

**3. 精確操作化定義**
- `w_i ∝ 1 / atr_pct_i`，在每日「帳上未平倉部位集合」內正規化至總和 1，單一部位上限 3× 最小權重（避免低波動股吃掉整個組合）
- 建構日頻 NAV：每日對所有未平倉部位按權重計算組合日報酬，扣成本（進出場當日各扣 0.285%）
- 評估指標改成：**年化報酬、年化波動、Sharpe、IR（對 ^TWII）、最大回撤、Newey-West t 值**，不再只看「平均每筆超額」
- 對照：等權版 vs 反波動版，跑在 baseline 與 core5 兩個母體上
- **事前預測方向：平均每筆超額幾乎不變，但 Sharpe/IR 改善，且 top2_share 大幅下降。**

**4. 為什麼這次不一樣**
前一輪整個研究的**評估單位**就是錯的——「平均每筆超額」是一個跟實際資金曲線脫節的指標，它既不反映集中度也不反映風險。這個假說不是找新訊號，是**把評估方式換成一個實務上真的能對應到帳戶淨值的東西**。這也是修正驗證規格裡「有效樣本是 93 天不是 1632 筆」問題的必要基礎建設：有了日頻 NAV，統計檢定才做得對。

**5. 可執行性檢查**
✅ ATR 用歷史資料；權重播出當晚可算。
⚠ 台股最小交易單位 1000 股，2330（~2380 元/股）一張要 238 萬——**對小資金帳戶，反波動加權在實務上做不到**。必須加一個「可零股交易」或「最小資金 N 元」的實務檢查，並且報告在資金 100 萬 / 500 萬 / 2000 萬三個規模下的可行性。這一點要誠實寫進結論。

**6. 預估樣本量**
93 個交易日的 NAV（有效樣本 = 93，不是 1632）。**這正是重點：一旦改用正確的推論單位，很多「顯著」會消失。**

### H12｜事前可得的大盤情境（修掉前一輪的未來資訊 bug）

**1. 假說陳述**
用**播出當下就能知道**的大盤狀態（TWII 相對 20 日均線的位置、20 日實現波動率分位）分組，推薦的 d3 超額在「大盤處於恐慌/回檔」的日子顯著較高。

**2. 為什麼可能成立**
兩個機制：
(i) 這批推薦本質上是**槓桿 beta**，在大盤跌深之後的反彈中彈性最大；
(ii) 更有意思的行為面理由——在恐慌日，老師被迫講**真的有理由的東西**（節目裡明顯看得到：大跌那幾天主持人反覆說「今天很辛苦，謝謝老師來扛」），而在大漲日節目氣氛是普天同慶、隨便講什麼都會漲，推薦的鑑別力最低。也就是說**訊噪比隨市場恐懼度上升**。

**3. 精確操作化定義**
- 情境變數（全部只用 D 日收盤前資料）：
  - `mkt_ext = TWII_Close_D / TWII_MA20_D − 1`（分 3 組：< −1%、±1%、> +1%）
  - `mkt_vol = TWII 20 日實現波動率`（三分位）
  - `mkt_5d = TWII 過去 5 日報酬`（三分位）
- 每個情境變數獨立分組，測 d3 超額的組間差異與單調性
- 進階（需重抽）：用 `analyze_free.py` 對 93 集的 `market_view` 欄位（平均 123 字，93 集全有）加一個 `market_stance: bullish/neutral/cautious` 的 LLM 分類，測**老師群體自己的情緒**是否為反向指標（**預測：群體最樂觀時後續最差**，這是經典的情緒反向指標）
- **事前預測方向：mkt_ext 低（大盤在均線之下）的組別 d3 超額較高。**

**4. 為什麼這次不一樣**
前一輪的 `bull_regime_only_m1` **用了未來資訊**（`ret − excess` 是持有期間的大盤報酬，見本文第 0 節）。所以「大盤濾網失敗」這條結論其實不成立——它測的是一個不可執行的東西，而且諷刺的是連那樣作弊都沒成功。本假說是它的第一個合法版本。另外用 `market_view` 文本做反向情緒指標，是 93 集裡完全沒被碰過的一個欄位。

**5. 可執行性檢查**
✅ TWII 的 MA20/波動率在播出當晚全部可得。
⚠ 93 集只跨約 4.5 個月，**大盤情境的獨立事件數極少**（大概就是 5 月漲、7 月初急殺、8 月初股災反彈這幾段）。分成 3 組後，每組雖然有幾百個部位，但**獨立的大盤事件只有 3~5 個**。這是本文樣本最弱的假說，很容易把「8 月初那一次反彈剛好很猛」誤判成通則。
⚠ 我必須誠實說：**這個假說即使測出漂亮的結果，我也不會相信它。** 建議把它定位成「排除 bug、留下記錄」，而不是尋找可交易策略。

**6. 預估樣本量**
部位數充足（每組 ~500），但**有效獨立樣本 ≈ 3~5 個大盤情境段落**。按驗證規格第 4 條，這個假說應該直接標記為「不可結論」。

## 3. 我明確不建議的方向（連同理由）

| 方向 | 為什麼不做 |
|---|---|
| **老師 × 持有期的個別最佳匹配** | 題目有提到，但這是多重比較的教科書級陷阱：23 位老師 × 4 個持有期 = 92 個檢定，在 α=0.05 下**期望會有 4.6 個假陽性**，而每位老師的樣本只有 40~185 筆。如果非做不可，**唯一可接受的作法是階層式貝氏收縮**（把每位老師的估計往全體均值收縮，收縮強度由樣本量決定），然後報告**收縮後的後驗**，而不是 23 個獨立的點估計。直接跑 92 個回測再挑最好的那幾個 = 保證產生垃圾 |
| **同集共識（≥2 位老師）的各種變體** | 實測：**1857 個部位裡只有 68 個是 ≥2 位老師同看同方向**（3.7%）。這個樣本從物理上就不可能得出可靠結論，前一輪的「共識 +16.9%」靠 2 筆神單撐起來是必然的。跨集擁擠度（H8）才是這個構念在本資料集裡唯一有樣本支撐的版本 |
| **用正則表達式在逐字稿裡數關鍵詞（語氣詞、猶豫詞）** | 題目有提到「逐字稿文本特徵」，但我實測 ASR 品質不支援：股票名稱原字串命中率只有 54%、老師姓名 21%。要做文本特徵**必須走 `analyze_free.py` 的 LLM 重抽取**，加結構化欄位（我在 H1/H4/H12 都寫了具體的欄位名）。省下的那點力氣不值得引入 46% 的非隨機遺漏 |
| **只買台積電 / 只買某個族群** | 前一輪已測，且本質上是把 93 集的資料縮到單一標的的時間序列，等於在賭一檔股票 4 個月的走勢 |
| **`target_price` 當成主要訊號** | 題目有提到，但實測只有 471/2259 筆非空，而且**大量是「支撐位/不破 XXX」而非上檔目標**；扣掉之後只剩 262 個部位有可用的上檔數字。它可以當 H5 的一個組件（有沒有給數字 = 準備程度），但撐不起一個獨立假說 |
| **加入三大法人買賣超資料** | 逐字稿裡老師每一集都在講投信/外資籌碼，這確實可能是真訊號，而且 TWSE 有免費 API。但這會引入一個新的外部資料源與新的一批自由度，**建議等上面 12 個做完再說**——現在加進來只會讓搜尋空間再爆炸一輪 |

## 4. 我認為最有突破潛力的前三名

### 🥇 第 1 名：H1 + H2（進場條件錯配）
**理由**：這是唯一一個指出**現行回測方法本身可能是錯的**的假說，而不是再加一個濾網。41% 的推薦老師明講「別現在買」，我們卻全部在隔天收盤市價買進——這不是一個小瑕疵，這是把分析師認為風報比最差的那一半系統性地買進來。它的樣本最大（965 vs 695）、訊號取得最乾淨（純文字，零未來資訊）、而且 H2 提供了一個真正沒被碰過的自由度（訂單類型）。
**但我也要說**：H1 的預測方向不一定會成立。有一個合理的反向劇本——「叫你等拉回」的股票是老師比較謹慎、比較不飆的股票，這類股票本來就比較溫和，而「立刻買」的往往是當天漲停的強勢股（追高），結果可能反而更差。**如果 H1 的符號是反的，那本身也是一個乾淨且可交易的發現**（跟 H3 的價格壓力反轉機制一致）。不管哪一邊，這個檢定都會有結論——這是我給它第一名的真正理由。

### 🥈 第 2 名：H6（beta 中性化）
**理由**：它是**元假說**。已知事實 #5 的 6:1 不對稱基本上已經自白了「這是高 beta 組合」，而現行 `excess` 假設 β=1 ⇒ 在上漲的樣本期裡，**β>1 會無中生有地製造正超額**。如果不先校正這把尺，後面 11 個假說的驗證結果全部都是可疑的。
**誠實預測**：我認為它有 **70% 以上的機率會把 core5 的 +1.2% 殺掉大半**。也就是說，這個假說的最可能結果是「壞消息」——但那是這個研究計畫現在最需要的東西：一個能讓我們停止追逐幽靈的乾淨結論。而萬一 core5 的 alpha 在 beta 中性後還活著，那它就從「可能是假的」升級成「大概是真的」，價值極高。所以它是不對稱有利的檢定。**建議第一個做，因為它會改變其他所有假說的評分標準。**

### 🥉 第 3 名：H8（擁擠度衰減）
**理由**：三個優點難得地同時具備——(a) 機制清楚且有文獻支撐（注意力買盤衰竭 + 價格壓力反轉）；(b) **樣本結構最漂亮**：0/1/2/3-4/≥5 五個桶，最小的桶也有 97 筆，且跨滿 93 集；(c) 它做的是**單調性檢定**而不是門檻篩選，對 data dredging 的抵抗力遠高於前 18 個策略的任何一個。而且它和前一輪失敗的 `first_mention_only`（同一位老師的第幾次）是真正不同的構念——實測跨老師的重複才是主流，那才是「擁擠」。
**風險**：`crowd_10 == 0` 的 798 個部位偏向冷門小型股，流動性成本會比 0.57% 高很多。所以即使單調性成立，**可交易性還要另外過一關**。

### 一句話的誠實總結
如果 H6 的結果是「beta 中性後 core5 的 alpha 消失」，而 H7 的結果是「看多 ≈ 觀望」，那麼**正確的結論就是這個資料集裡沒有 alpha，應該停手**——而這兩個檢定加起來只需要一天工作量。我建議先做這兩個「可能終結計畫」的診斷，再決定要不要投入資源做 H1/H2/H9/H10 那些比較耗工的交易型假說。
